# TuxDash — Chrome Theme

A Chrome extension that brings a beautiful, dark Linux-inspired wallpaper to your new tab page.

TuxDash dynamically changes the wallpaper when you open a new tab, giving your browser a fresh Linux-themed experience every time.

## Features

- Linux and Tux-inspired wallpapers
- Dark, modern visual style
- Dynamic wallpaper selection
- 10–15 curated wallpapers
- Lightweight and fast
- No external dependencies
- No user data collection
- Designed with privacy in mind

## Technology

- HTML
- CSS
- Vanilla JavaScript
- Chrome Extensions Manifest V3
- Image Size 1920 X 1080

## Privacy

TuxDash is designed to work locally without unnecessary permissions, external services, or user tracking.

The extension does not require a backend or database.

## Status

The core extension is functional, and new features are currently being developed.
